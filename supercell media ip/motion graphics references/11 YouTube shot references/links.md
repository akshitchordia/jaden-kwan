# YouTube shot references: Supercell reel

Thumbnails in this folder use the same numbers.

## Watch for the look
- **01. [How I Make My Maps](https://www.youtube.com/watch?v=GsojLuJpe_0)** · Johnny Harris · 29:29  
  The map language to copy: dark base, thin borders, one place lights up, camera pushes in. For the Canada/Australia beat and "one country".
- **02. [Why everyone’s mad about China’s new map](https://www.youtube.com/watch?v=WpQQOQ__1ok)** · Johnny Harris · 16:29  
  Johnny Harris maps in a finished video. Watch how the zoom-ins carry the story.
- **03. [How VOX breaks the Digital Feel with Motion Graphics](https://www.youtube.com/watch?v=sACZlG7z35Q)** · Chris Moran · 12:30  
  Why Vox graphics feel tactile, not digital: paper texture, print grain, imperfect edges. Same idea as our halftone.
- **04. [The Information Society Retro Motion Graphic Design (1980)](https://www.youtube.com/watch?v=Gdw5RVIG1yA)** · Jake Sturgess · 0:15  
  Real 1980 broadcast graphics. Use it for the retro terminal and number beats.
- **05. [Retro computer UI animation.](https://www.youtube.com/watch?v=rtzu2QZYfsE)** · VFX Calin · 0:20  
  Retro computer UI moving: blinking cursors, line-by-line reveals.
- **06. [Glowing Network lines lighting up world map - DEMO](https://www.youtube.com/watch?v=Y5fB1ORbuEQ)** · webcareGR · 0:31  
  Network lines lighting up a map, for the "one city" beat.
- **07. [The Chess Game l Cinematic Chess B Roll l Edelkrone](https://www.youtube.com/watch?v=0mvwoxMdFkM)** · Augustin THAI · 0:54  
  Cinematic chess B-roll: low angle, shallow focus, slow slider. "Pick a market".
- **08. [TV On and Off Effect (After Effects)](https://www.youtube.com/watch?v=V-nbvAnq65I)** · N-Forced · 0:05  
  The classic TV-off collapse: picture to line to dot. "By February, it was gone".
